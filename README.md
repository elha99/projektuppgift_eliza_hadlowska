# Hotell Tass
Webbplatsen innehåller information och kontaktuppgifter till ett fiktivt hundpensionat. Det är ett familjeägt företag som med sin kärlek till hundar vill skapa en trygg plats för hundar, 
så deras ägare kan slappna av på sin semester/arbetsresa.


## Tekniker
Projektet är byggt med:  
-HTML  
-CSS  
-JavaScript
